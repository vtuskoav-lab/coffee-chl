# coffee-chl
Coffee CHl ☕

Where Every Cup Tells a Story

Coffee CHl is a coffee shop website created as a student web development project. It features a warm color palette, a welcoming hero section, and information about the coffee shop.

🌐 Live Demo

Visit the website: Coming soon!

✨ Features

* Clean and modern design
* Warm, coffee-inspired color palette
* Navigation menu
* Hero section with a welcome message
* Interactive buttons with hover effects
* Coffee shop contact information and opening hours
* Responsive layout elements

🛠️ Technologies

* HTML5
* CSS3

📁 Project Structure

coffee-chl/
├── index.html
├── style.css
├── coffee.jpg
└── README.md

🚀 Getting Started

To view the website locally:

1. Clone or download this repository.
2. Make sure all project files are in the same directory.
3. Open index.html in a web browser.

🎯 Project Purpose

This project was created to practise HTML and CSS. It demonstrates the use of CSS selectors, page layout, typography, colors, and interactive styling.
